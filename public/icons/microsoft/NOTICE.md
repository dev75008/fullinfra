# Icônes Microsoft

Ces fichiers SVG proviennent des collections officielles suivantes :

- [Icônes d’architecture Azure](https://learn.microsoft.com/fr-fr/azure/architecture/icons/), pack Azure Public Service Icons V24.
- [Icônes d’architecture Microsoft Entra](https://learn.microsoft.com/fr-fr/entra/architecture/architecture-icons), pack d’octobre 2023.

Ils sont utilisés pour identifier les produits Microsoft dans les diagrammes et la documentation pédagogique InfraLab. Ils ne représentent pas la marque InfraLab. Microsoft conserve ses droits sur ses icônes et marques.

Les conditions publiées par Microsoft autorisent leur utilisation dans des diagrammes d’architecture, des supports de formation et de la documentation. Les SVG sont conservés sans modification, recoloration, recadrage, rotation, retournement ou déformation. Le nom du produit apparaît à proximité. Toute réutilisation doit respecter les conditions des pages officielles ci-dessus.

`manifest.json` indique l’origine dans chaque archive et l’empreinte SHA-256 des fichiers copiés. `npm run check:icons` vérifie leur intégrité.

Les autres pictogrammes du site utilisent Lucide (licence ISC) ou du dessin SVG original. Ils sont distincts des logos officiels et servent à représenter les notions transversales ou les technologies locales.
