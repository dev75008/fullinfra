# Icônes Microsoft

Ces fichiers SVG proviennent des collections officielles suivantes :

- [Icônes d’architecture Azure](https://learn.microsoft.com/fr-fr/azure/architecture/icons/), pack Azure Public Service Icons V24.
- [Icônes d’architecture Microsoft Entra](https://learn.microsoft.com/fr-fr/entra/architecture/architecture-icons), pack d’octobre 2023.
- [Icônes d’architecture Microsoft 365](https://learn.microsoft.com/fr-fr/previous-versions/microsoft-365/solutions/architecture-icons-templates), pack Microsoft 365 Content Icons 2024 pour les personnes, les appareils, le cloud et les notions de sécurité.
- [Icônes de produits Fluent UI](https://fluent2.microsoft.design/iconography/), fichiers distribués par le CDN Microsoft Office pour Outlook, Teams, SharePoint, OneDrive, Word, Excel, PowerPoint et OneNote.
- Ressources des dépôts officiels Microsoft [Agent Academy](https://github.com/microsoft/agent-academy/tree/main/docs/public/product-icons) et [Microsoft AI Decision Framework](https://github.com/microsoft/Microsoft-AI-Decision-Framework/tree/main/images/icons) pour les visuels Microsoft, Copilot, Exchange, Intune, Defender et Purview.

Ils sont utilisés pour identifier les produits Microsoft dans les diagrammes et la documentation pédagogique InfraLab. Ils ne représentent pas la marque InfraLab. Microsoft conserve ses droits sur ses icônes et marques.

Les conditions publiées par Microsoft autorisent leur utilisation dans des diagrammes d’architecture, des supports de formation et de la documentation. Les SVG sont conservés sans modification, recoloration, recadrage, rotation, retournement ou déformation. Le nom du produit apparaît à proximité. Toute réutilisation doit respecter les conditions des pages officielles ci-dessus.

`manifest.json` indique l’origine dans chaque archive ou l’URL de téléchargement, ainsi que l’empreinte SHA-256 des fichiers copiés. `npm run check:icons` vérifie leur intégrité. Les icônes de l’infographie Microsoft 365 sont également embarquées à l’identique dans le SVG sous forme d’images encodées en base64, sans dépendance à un CDN lors de l’affichage ou du téléchargement.

Les autres pictogrammes du site utilisent Lucide (licence ISC) ou du dessin SVG original. Ils sont distincts des logos officiels et servent à représenter les notions transversales ou les technologies locales.
